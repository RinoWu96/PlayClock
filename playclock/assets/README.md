Files bundled into the exe by `build.bat` (`--add-data playclock\assets`).

- `miniprogram_qr.png`: the WeChat mini program code shown under Settings → 手机查看. Download it from
  mp.weixin.qq.com (设置 → 基本设置 → 小程序码) once the mini program is published. Without it the
  card shows a "coming soon" placeholder.
